🔥 Configuración Firebase
Conecta tu proyecto Firebase para guardar plantillas y usuarios en la nube.
No conectado — completa los pasos abajo
📋 Pasos para crear tu proyecto Firebase gratuito
1
Ve a console.firebase.google.com e inicia sesión con tu cuenta Google.
2
Clic en Crear un proyecto → Ponle cualquier nombre → Acepta y continúa.
3
En el menú izquierdo: Firestore Database → Crear base de datos → Seleccionar "Modo de prueba" → Elegir región (ej. us-central1) → Listo.
4
En el menú izquierdo: Authentication → Comenzar → En "Métodos de acceso" activa Correo electrónico/Contraseña.
5
Ícono ⚙️ Configuración del proyecto → pestaña "Tus aplicaciones" → clic en </> Web → ponle un nombre → copia el firebaseConfig.
6
Pega los datos en el formulario de abajo y clic Guardar y conectar.

🔒 Reglas de seguridad Firestore

Copia estas reglas en Firestore → Reglas, para que cada usuario solo vea sus diseños:

rules_version = '2'; service cloud.firestore { match /databases/{db}/documents { // Plantillas: todos los usuarios autenticados las ven match /templates/{id} { allow read: if request.auth != null; allow write: if false; // Solo desde admin } // Diseños: solo el dueño match /user_designs/{id} { allow read, write: if request.auth != null && request.auth.uid == resource.data.uid; allow create: if request.auth != null; } } }

Ve a Firestore → Reglas → Pega esto → Publicar
